# Firewall Rules Lab

## Objective

Understand how firewall rules control network traffic based on source IP address, destination IP address, port number, and action.

## Rule Configured

Source IP: 198.51.100.34

Destination IP: 203.0.110.1

Port: 80 (HTTP)

Action: DROP

## Screenshot

![Firewall Rule Demo](https://github.com/user-attachments/assets/8f97d3e9-aa3b-496c-b432-35ccc13344d8)


## Result

Traffic from 198.51.100.34 to 203.0.110.1 on port 80 was blocked by the firewall.

## Concepts Learned

- Firewall filtering
- Source and destination IP addresses
- Network ports
- Access control
- Traffic blocking using DROP rules
